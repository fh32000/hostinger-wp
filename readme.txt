== Description ==

إضافة **WooCommerce Quick Pay & Pay Links** توفر حلاً احترافياً للمتاجر والمؤسسات التي تحتاج لصفحة دفع حر ومباشر وسداد فواتير سريعة دون الاعتماد على مظهر قوالب ووردبريس المزدحم.

### المميزات الرئيسية:
* **صفحة دفع مستقلة عصرية (Standalone):** صفحة أنيقة وخالية تماماً من تشتيت القوائم والترويسات والتذييلات المزدحمة.
* **دفع بمبالغ حرة ومتكررة:** إمكانية إدخال أي مبلغ أو اختيار من مبالغ محددة مسبقاً (50، 100، 250، إلخ).
* **تمرير تلقائي فوري لبيانات العميل:** الاسم، البريد، الجوال، ورقم الفاتورة تنتقل مباشرة إلى الطلب وبوابة الدفع دون الحاجة لإعادة إدخالها.
* **ربط مباشر ببوابات الدفع:** دعم كامل لبوابة البنك الأهلي التجاري (AlAhli MPGS)، مدى، البطاقات الائتمانية، وأي بوابة مفعلة في ووكومرس.
* **تخصيص كامل للأقسام:** التحكم في الشعار، العنوان الترحيبي، الوصف، شارة الأمان، والتذييل وروابط الدعم (واتساب، هاتف، إيميل).
* **مُولّد الروابط السريعة:** أداة لإنشاء روابط فواتير مجهزة للمشاركة بنقرة واحدة مع زر نسخ وزر إرسال واتساب.
* **دعم الرمز القصير (Shortcode):** إمكانية تضمين النموذج عبر `[wc_quick_pay]` في أي صفحة أو باستخدام أداة بناء الصفحات مثل Elementor.
* **توافق تام مع HPOS:** تدعم نظام التخزين عالي الأداء لطلبات ووكومرس.

== Installation ==

1. قم برفع مجلد الإضافة `wc-quick-pay` إلى المسار `/wp-content/plugins/`.
2. قم بتفعيل الإضافة من خلال قائمة "الإضافات" في ووردبريس.
3. توجه إلى "WooCommerce" > "الدفع السريع ⚡" لتخصيص الإعدادات وتوليد الروابط.
